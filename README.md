# 📊 Deloitte Australia – Data Analytics Job Simulation

## 📌 Project Overview

This project is based on the Deloitte Australia Data Analytics Job Simulation, completed through Forage.

The simulation provided practical exposure to real-world business scenarios through two assigned tasks. I worked with a dataset provided as part of the simulation, used Tableau to create dashboards, and explored how data analytics can help solve business problems.

I successfully completed both tasks and achieved a score of **9/10**.

## 🎯 Project Objectives

- Analyze the provided dataset.
- Create dashboards using Tableau.
- Identify insights to address real-world business problems.
- Explore the application of data analytics in Forensic Technology.
- Understand how data-driven insights support business decisions.

## 📝 Tasks Completed

### Task 1: Data Analysis and Dashboard Development

- Worked with the dataset provided during the simulation.
- Analyzed the data to understand and solve business problems.
- Created dashboards using Tableau to present key insights.
- Used data visualization to communicate findings clearly.

### Task 2: Forensic Technology

- Completed a task focused on Forensic Technology.
- Gained exposure to the use of technology and analytical approaches in forensic-related scenarios.
- Developed a better understanding of how analytical thinking can be applied to practical business tasks.

- **Data Analytics:** Exploring data and identifying insights.
